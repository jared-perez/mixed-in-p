The full audio file prep workflow for DJs · v1.5.0

Mixed in P helps you organize, rename, convert, and tag your library, then analyzes every track for BPM, musical key, and energy — all in one compact desktop app built for DJs.

01What is Mixed in P

Mixed in P is a desktop app for DJs and producers that turns a folder of tracks into a well-understood, well-organized library. Drop your files in and it detects:

  • BPM (tempo) with a confidence score,
  • Musical key, shown as a harmonic key code (e.g. 8A),
  • Energy level (1–10), a quick feel for a track's intensity.
  • Audio quality — the Spectrum view's frequency graph reveals the high-frequency cutoff of a low-bitrate or upscaled file, so you can catch fakes before they reach your set.

From there you can batch-rename files with the tempo and key baked into the name, convert between lossless formats, edit tags and artwork, and audition or slice tracks in the built-in player. It runs on Windows and macOS (Apple Silicon and Intel).

04Core workflows

Analyze tracks

Drop files onto the Analysis panel and they analyze automatically. Each row shows BPM, key, key code, energy, and confidence percentages, plus a color-coded status.

  • The Auto toggle controls whether dropped files analyze instantly; with it off, files wait as pending until you press Analyze.
  • The table shows the whole queue, not just the finished tracks. Every file appears the moment you add it, and its Status updates live — Pending, Analyzing, Analyzed, Error — so a long batch shows you where it has got to.
  • Detected BPM and key can be written back to the file's tags (see Settings).
  • Right-click a row to Open File Location or Remove; Clear Results empties the table.
  • Drag selected rows onto another panel's sidebar button to push them to Convert, Rename or the Player — see Getting files in and out.

Cancelling a run. The Cancel button appears beside the progress bar while a run is going and disappears when there is nothing left to stop. Cancelling ends the batch as soon as the current track lets go — a long track can take a few seconds, since key detection is one uninterruptible pass — and the file it was working on is discarded rather than half-recorded.

Cancelling doesn't undo the tracks that already finished. They keep their results, their tags, and their new filenames if auto-rename is on. Cancel stops the remaining work; it is not an undo. To roll back the renames, use History.

Freeze — analyze without touching your files. The Freeze toggle sits next to Auto in the Analyze header. With it on, analysis still runs and still shows you every result, but it writes nothing to your files: no BPM or key tags, no energy or key comment, no auto-rename. It is the way to survey a folder you don't want modified — a borrowed drive, or files you haven't decided about yet.

  • It is a session switch: it always starts off, and it never changes your Settings. Turn it off and your normal write settings are exactly as they were, because they were never touched.
  • It only covers the analysis flow. Edits you make yourself in the Metadata panel or the Player, and Apply Rename in the Rename panel, all still work normally.
WAV files can't store BPM or key. The format has no tag for them, so an analyzed WAV is flagged in the table — a tinted row, and a Status of WAV file before it runs or Analyzed, no tags after. The analysis itself is still worth running: the BPM, key and energy are shown on screen, and auto-rename still writes them into the filename, which is the one place a WAV can carry them. Convert it to AIFF or FLAC if you want real tags.

Organize & batch-rename

The Rename panel rewrites many filenames at once, with a live before/after preview.

  • Trim characters from the start and/or end of every name.
  • Prepend and/or Append custom text — two independent toggles over two boxes, so one pass can do both. Typing in a box arms its own toggle. The text is added to the beginning and/or end of ALL the filenames being renamed.
  • Remove underscores replaces _ with spaces.
  • Space Dashes puts a space on each side of a bare dash: Artist-Track becomes Artist - Track. Some DJ software searches artist and track names poorly when a dash is wedged between them with no spaces, and this fixes a whole folder of them at once. It only touches a dash with a non-space character on both sides — names that already read a - b, one-sided ones like a -b, and a dash at the very start or end are left exactly as they are, so it is safe to run over a mixed folder.
  • Changes show in green; conflicts (duplicate results) block Apply Rename until resolved.
  • Undo Last reverts the most recent batch; older batches undo from History.

Convert formats

  • Pick a target format: AIFF, WAV, FLAC, or MP3.
  • Lossless targets offer sample rate (96 / 48 / 44.1 / 32 kHz) and bit depth (32 / 24 / 16 / 8-bit);
    MP3 offers a bitrate (128 / 192 / 256 / 320 kbps).
  • Keep source — the first choice on both — leaves that setting exactly as the file already has it. It's the one that suits a mixed batch, where a single rate can't fit every source, and the only one available to a file below 32 kHz.
  • Sources must be lossless (WAV, FLAC, AIFF) — lossy files are rejected as sources.
  • Quality only ever goes down. A sample rate or bit depth higher than the source's is refused — the row reads Would upsample — because nothing can put back detail the file never had. Matching them is always fine.
  • Same format, lower quality is allowed: a 96 kHz/24-bit FLAC can become a 44.1 kHz/16-bit FLAC for older CDJs and players. Into the format a file already has, only a lower setting does anything — matching ones read Same format and are skipped.
  • Where the files go is the end of the row: a folder button to choose a destination, and a Source toggle beside it. Lit (the default) means each file lands next to its own original, so a batch spanning several folders stays where it came from — the row reads Same folder as source. Choose a folder and the toggle goes out by itself; the path is shown from its deepest folder back, since that is the part that identifies it, with the whole thing on hover.
  • The toggle works both ways: switch Source back on to write beside the originals again, and off to return to the folder you last picked — it is remembered, so going back is one click and not another trip through the file dialog. Both survive a restart. A folder deleted in the meantime is forgotten rather than failing a batch, and nothing is ever overwritten: a name already taken gets a (1), (2) and so on.
  • Drag the converted rows onto another panel's sidebar button to move them to Analyze, Rename or the Player.
  • Cancel appears beside the progress bar while a batch is converting. Files already written are kept; the one in progress is discarded.

Run the pipeline

Renaming a folder, converting it, analyzing it and filing it into a playlist is four trips through three panels. The pipeline is those trips as one press.

The step toggles. Rename, Convert and Analyze each carry a small hazard-wave triangle. Switch one on and that step is part of a pipeline run; that panel's action button changes from Apply Rename / Convert / Analyze to Start Pipeline to say so. The order is fixed — rename → convert → analyze → playlist — and the toggles only choose which steps take part, never the sequence.

The header cluster. The same three triangles appear in miniature in the app header, beside a playlist field. Either set of toggles drives the other, so you can see and change the shape of a run from anywhere in the app. The field appears as soon as any step is on and folds away when they are all off. Pick an existing playlist from the list, or type a name and one gets made when the run finishes — typing is what tells it to create, so a name that matches one you already have still makes a new playlist unless you pick it from the list.

Starting a run. Press Start Pipeline in whichever enabled panel holds the files you mean. The run takes that panel's files and flows through the later enabled steps only — so a batch started in Convert with all three on is converted and analyzed, and Rename is not applied to it retrospectively. Every run ends in the target playlist whatever else is switched on: with Analyze off, tracks land there un-analyzed, which is exactly what you want for a folder you have already been through.

  • Each track is filed into the playlist as its own analysis finishes, so a long batch fills the playlist while it runs rather than all at once at the end.
  • Turning a step off is a real skip, not a no-op: an Analyze-off run never starts the analyzer, and a rename that would change no filenames asks once and then moves on.
  • Flipping a toggle mid-run does not re-route a batch already in flight — the run remembers the shape it started with.
  • Auto-analyze (Settings) is independent of all this. It analyzes files as they are dropped; the pipeline drives its own analysis whether or not that is on.

Edit metadata & artwork

Drop a single file onto the Metadata panel to edit Title, Artist, Album, Label, Genre, BPM, Key, Year, Track #, and Comment. Changes save automatically when you leave a field. Add fields with Add field…, embed a cover image by dropping it or clicking Add Artwork…, and unload with Eject. Reload re-reads the file from disk to pick up tag changes made elsewhere — for example, edits you made inline in the Player playlist.

The panel header names the file you are editing on two lines: the filename, and beneath it the full path it came from, shortened with an ellipsis if it is too long for the panel (hover it to read the whole thing). Open File Location beside it opens that folder in Finder or Explorer with the file selected — useful when two tracks share a name and you need to know which one you have open. Right-click the path for the same thing plus Play in Player, which loads the file into the Player without leaving the panel, and Copy File Path.

Beside the filename the header reads out what the audio actually is: Sample Rate and Bit Depth for a file whose stream has them, and Bitrate instead for one that does not — an MP3, M4A or OGG, where the bitrate is the meaningful number. It is a quick way to see that the "lossless" file you were sent is 44.1 kHz / 16-bit and not what its extension claims.

The cover sits in a column of its own beside the fields. Click it to see it full size in a lightbox, which is the only way to tell a crisp 1400px scan from a 300px thumbnail somebody embedded years ago. Right-click it for Remove Artwork — it lives on the cover's own menu now rather than as a button in the row, so a destructive action is on the thing it destroys.

Fill in tags from Discogs

Tracks arrive with half their tags missing, and the things this app cannot work out from the audio — the label, the year, the album a track came from — are exactly the ones a discography knows. Online lookup is off by default, and while it is off the app makes no network requests at all and the buttons below do not appear. Turn it on in Settings → Online Metadata and paste a free Discogs token.

  • One file — load it in the Metadata panel and click Look Up Online….
  • A whole selection — select the rows in the Player playlist, right-click, and choose Look Up Online…. The queue runs behind a progress bar you can cancel, then the results are reviewed one file at a time.

Either way you get a review window listing your current value beside the proposed one, with a tick box per field. Nothing is ever written without a tick. A field you have already filled in starts unticked — the lookup will not overwrite your own work unless you say so — and an empty field starts ticked; Select All is one click when you are deliberately re-tagging. Fields that already match are not listed at all. If the best match is a weak one, the window says so instead of pre-filling confidently, and the Select release dropdown at the top switches to any of the other pressings the search found. A second dropdown, Select track, says which track of that release this file is — useful on an album or a compilation, where the release is right and only the position is in doubt.

What can be filled in: Title, Artist, Album, Label, Genre, Year, Track # and cover art. Genre comes from Discogs styles ("Techno", "Deep House"), not its coarse genre field. The year prefers the original release over the repress you happened to match. Cover art is previewed next to your file's own so you can compare them, and is written only if you tick it — turn the fetch off entirely in Settings if you would rather not.

The app remembers which release a file was tagged from. Once you have applied a lookup, the Metadata panel says Applied from Discogs beside the button, with a View release link that opens that release's page in your browser. A second look at the same file opens on the release you approved rather than searching from scratch — so a track you tagged months ago is still tied to the right pressing, and a file you have already been through does not have to be identified twice. The memory follows the file, so it survives a rename, and it works on a file the Metadata panel has never imported into your library.

The Discogs tab. With a release remembered, the Metadata panel grows a second tab beside Tags, named Discogs. It holds the release as Discogs describes it — kept on your machine, so it reads with no network at all:

  • Release — label, catalogue number, year, styles and genres.
  • Pressing — format, country, and the date it was released.
  • Tracklist and Credits — the full listing, selectable so you can copy from it.
  • An apply arrow beside a row writes just that value into the file's tags — one field at a time, without running the whole review again. A row already matching your tags says so instead of offering the arrow.
  • Refresh from Discogs reads the release again, for a listing that has been corrected or filled in since you last looked.

Find Cover Online…, on that same tab, is the lookup reviewing the sleeve alone: search Discogs, compare covers, and take one without touching any other tag. Useful when the tags are already right and the artwork is all that is missing.

A file with no tags at all is not a dead end either — the empty panel offers "No tags on this file — look it up on Discogs?" and starts the search from there. And in Settings → Online Metadata, pasting a token switches the lookup on by itself: having supplied one is the only reason to paste it. If you have not set the lookup up yet, Discogs Setup at the top right of the Metadata panel takes you straight to those settings.

BPM, key and energy are never fetched. Discogs does not hold them, and they stay the product of this app's own analysis of your actual file. A WAV can be looked up — reading the values is still useful — but the window will remind you that WAV files hold no tags, so nothing will stick.

Lookups are paced to Discogs' rate limit (about 20 tracks a minute), and a batch that has to wait says so rather than sitting there. Nothing about your library is uploaded: a lookup sends the artist and title of the track you chose, and nothing else — never the audio.

Play, audition & lift samples

  • Player transport: Previous / Play-Pause / Stop / Next, a click-or-drag seek bar, and volume.
  • The playlist opens on #, cover art, artist, title, BPM, key, comment, duration, year, and filename. Double-click to play, drag to reorder, and right-click to open the file location, reload a track's tags from disk, or remove tracks; your column layout is remembered.
  • Edit tags inline: slow-double-click a cell — click an already-selected row again, the way you rename in Finder/Explorer — to edit Artist, Title, BPM, Key, Comment, or Year directly in the playlist; changes save straight to the file. The Edit Lock toggle at the top-right turns inline editing on/off — it starts unlocked and remembers your choice, so you can lock the list against accidental edits.
  • A panel shows the tags it loaded until you refresh it. Right-click → Reload Metadata from File in the Player (or Reload in the Metadata panel) re-reads the file from disk — handy after editing the same track in the other panel.
  • The next track pre-loads in the background, so Next is instant.
  • Playback carries on when you leave the Player, so the app header names the track that's running — beside the "DJ Audio Analysis Toolkit" line — on every other panel. Click it to jump back to the Player with the playlist that track came from open.
  • Waveform: the full-track waveform for the loaded track. Click or drag anywhere on it to move playback — it replaces the seek bar while it's open — and drag the green/red markers to set a slice.
  • Zoomed Wave: a ±0.5 s window around the playhead, for reading the beat under the cursor. Open on its own it leaves room for the metronome below without scrolling.
  • Loop Slicer: the slice controls — set start/end markers, nudge them, toggle an A–B loop, pick a format, and export the slice, ideal for lifting loops and samples by ear. The buttons are independent: open any on its own, or all three together for the full working slicer.
  • Metronome: the last of the collapsible sections, for tapping out a tempo and working over it. The tempo box reads to two decimals — drag it up or down to scrub, hold Shift while dragging for hundredths, or use the small +/− buttons for whole beats. Tap sets the tempo from your own timing, and the two hold-to-bend buttons lean the beat back or push it forward while held. Start sits on the section's own header row.
    • Pick the click: three exclusive buttons — ⊘ silent (the beat light still keeps time), ) the standard tick, and )) a sharper, longer beep that carries over a track you're playing underneath it.
    • How loud is the bars button beside them: press to cycle quiet / medium / loud. Silent stays on the click row, because which click and how loud are different questions.
    • Global Click, on by default, keeps the click going when you leave the Player, so a tempo you set once carries while you work in Rename or Convert. Turn it off and leaving silences it. Collapsing the section silences it either way.
    The click is scheduled sample by sample in the audio callback, so it holds a tempo indefinitely without drifting.
  • The waveform's color is configurable in Settings.

Compatible Tracks

The button beside the visuals eye — two interlocking rings, at the top-right of the Player — splits the playlist area and lists what else in your library mixes with the track loaded in the player. Drag the divider to give it more or less room; it opens closed each session.

The list is ranked, best first, and the Key colour says which kind of match each row is:

Key colourRelationship
YellowSame key — the same code as the seed.
GreenRelative major/minor — same number, other letter (8A ↔ 8B).
PlainOne step around the wheel — ±1 on the same letter (8A ↔ 7A, 9A).

Within a key tier, tempo decides: tracks nearest the seed's BPM come first, inside a ±8% window. Half- and double-time matches count — a 64 BPM track under a 128 BPM seed mixes perfectly well — and their BPM is shown in blue so you can see what you're getting; hover it and the tooltip says which way round it is. After that, energy (the E column) breaks the tie: the closest energy level to the seed's ranks higher. A track nobody has analysed yet still appears, at the end of its tier, rather than being hidden.

The Track column is as wide as the longest name in the list rather than as wide as the panel, so a long title is never cut off — scroll the list sideways to read it instead of surrendering half the playlist to the divider.

Preview without stopping to load anything. Click the play icon in the left gutter of a row and it starts; the sound continues only while you keep the pointer on that icon, and moving off stops it. Clicking again while it plays skips 30 seconds forward, so a second and third click walk you into the track. Starting a preview stops the main player, and the main player stays stopped when you let go — nothing comes back on by itself.

Double-click a row to add that track to the playlist you're looking at, or drag rows out to another playlist, to the tree, or to Finder/Explorer. Dragging always copies — the list is a search result, so there is nothing here to move out of.

Nothing listed? The panel says which reason it is. “No key for this track — analyse it first” means the seed has no key the app can read: run it through Analyze. “This track isn't in your library yet” means the seed is playing from outside your playlists — matching works from library rows, so add it to a playlist first. And “Nothing in your library mixes with this track” is the honest answer: nothing you own is in a compatible key at a workable tempo.

Playlist columns, artwork & text size

Right-click the playlist's column header for the full list of columns. Tick one to show it, untick it to hide it again — the entries are toggles, so clicking a column that is already showing switches it off. Nine columns are available beyond the ones you start with:

ColumnShows
ArtThe track's cover art. On by default, second in the row.
AlbumThe album tag.
GenreThe genre tag.
Track #The track number within its album.
LabelThe record label (the publisher tag).
Bitratekbps. Lossless files are shown at their true rate — a FLAC reads 1411, not the compressed figure — so a real lossless file never looks worse than a 320 MP3 beside it.
EnergyThe 1–10 energy level from analysis.
Date AddedWhen the track was added to your library, as YYYY-MM-DD — so it sorts chronologically rather than alphabetically. Sort on it to find what came in this week.
Date CreatedThe file's own creation date, in the same format. Not the same thing as Date Added: a track ripped years ago and imported yesterday differs on the two.

These columns are read-only and drawn from the tags already loaded, so switching one on is instant. # and Filename are always present and aren't in the menu.

Fit a column to what's in it. The last entry on that same right-click menu names the column you clicked on — Fit Album to Longest — and sizes it to the longest value the playlist currently holds, header word included. It is one shot on purpose: a track added afterwards with a longer value will clip until you ask again, because a width that kept tracking the contents would move under your hand every time a playlist grew. # and Art aren't offered it — one is a fixed counter, the other follows the row height — and right-clicking past the last column leaves the entry off.

Lost track of your layout? Reset Columns — on that same right-click menu, under a separator below the column list — puts the playlist back to the columns, order, and widths it ships with, in one click. It's the way back if you've hidden something and can't remember what.

Cover art in the list. The Art column shows each track's sleeve, and Settings → Playlist Artwork chooses how much of it you see:

  • Top (default) — a wide band cut from the top of the sleeve, sized to sit in a normal row without making the list any taller.
  • Middle — the same band taken from the centre of the sleeve instead. Which part identifies a cover differs from record to record, so it's worth trying both against your own artwork.
  • Full — the whole square. Rows grow to fit it, turning the playlist into a browsing view rather than a list.

A track with no embedded artwork simply leaves an empty cell. Covers load in the background for the rows on screen, so scrolling a long playlist stays smooth.

Text size. Settings → Playlist Text Size offers Small, Medium (default) and Large for the playlist's rows. It applies straight away — no restart — and the row height, column widths and artwork all scale with it.

Build & manage playlists

Click Playlists at the top of the sidebar. The nav rail is replaced by your playlist tree — click it again to get the panel buttons back. The tree holds folders, saved playlists, and Scratch; click any playlist to load it into the Player.

Scratch is the working list. It is where the Player starts, where dragged-in files land, and where anything you open from Finder or Explorer goes. Treat it as a scribble pad: it empties every time you launch unless you turn on Keep Scratch between sessions in Settings. Anything worth keeping gets Save Playlist.
  • Save Playlist in the Player turns whatever is currently listed into a saved playlist in the tree.
  • Saved playlists auto-save. Once a playlist is loaded, adding, removing, or reordering tracks is written immediately — there is no Save button and no "unsaved changes" prompt. That is why undo matters: Ctrl+Z (Cmd+Z on macOS) steps back through this session's list edits, in both the Player and the tree.
  • Add tracks by dragging — drag rows from the Player, Analysis, or Convert onto a playlist in the tree. You can also drag the “Playing: …” line itself, which is the handle for the current track when its row isn't on screen.
  • Find your way back. Playback keeps going when you open another playlist, so the line under the transport also names the list the current track came from — “In Playlist: …”. Click that name to open it again, wherever you have wandered to.
  • Organize by dragging — move playlists into folders, and folders into folders. Which folders you left open is remembered between sessions.
  • Right-click a folder — or empty space, to work at the top level — for New Playlist and New Folder. Right-clicking a folder or playlist also offers Rename, Delete…, and the export actions below. Scratch can be exported like any other playlist, but not renamed or deleted.

Find a playlist by name. The magnifier beside + Playlist at the top of the tree opens a filter box. Type any part of a name and the tree narrows to matching playlists and folders, keeping the folders they live in visible so you can see where they sit. Folders are opened as needed to reveal a match, and closing the box (Escape, or the magnifier again) puts the tree back exactly as you had it. This filters the tree by name — for finding a track, use the Player's search below.

Search. The Player's search box has a scope button beside it: search this playlist or all playlists. Searching everything highlights the folders and playlists containing matches, so you can see the trail through the tree to a track you only half-remember.

Search looks atIt does not look at
Artist, title, album, filename, comment, key BPM

BPM is left out deliberately — as free text it is more noise than help, since a search for 128 would also match a comment, a year, or a filename that happens to contain those digits.

A search across all playlists returns up to 2,000 tracks; past that the count reads 2000+ and you should narrow the term. That is a limit on results only — there is no cap on how many tracks a playlist can hold.

Export. Right-click a playlist for Export…, a folder for Export Folder…, or use Export All Playlists… in Settings to write your whole tree out as a folder of playlist files. Formats are .m3u8, .m3u, and a readable .txt.

  • Prefer .m3u8 — it is UTF-8, so accented and non-Latin filenames survive. .m3u uses the system codepage and can mangle them.
  • Paths are written relative to the playlist file when the tracks sit beside it, so a folder you zip and send still works on someone else's machine. Always use full paths in exported playlists in Settings overrides that.
  • Export and Copy Tracks… writes the playlist and copies the audio files alongside it — the one to use for a USB stick.

Moved or missing files. A track whose file has gone is prefixed with ! in the list, and hovering it shows the last known path. Right-click and choose Locate Missing File… to point at its new home. Mixed in P then matches your other missing tracks against that folder, which makes a relocated folder one job rather than one per track. It matches on the file's contents rather than its name, so tracks you renamed as well as moved are still found; a file that was re-encoded (new contents) is matched by filename instead, and only when exactly one candidate carries that name.

Duplicates. Adding a track a playlist already contains asks what you want by default — a set list can repeat a track on purpose. Change it once in Settings → Playlists to always add or always skip.

Keyboard & harmonic reference

A 3-octave piano you can play with the mouse or QWERTY keys (Z / X shift the octave), with Minor/Major chord modes. A linear key strip and hex grid light up to show a key's harmonic neighbors — click any segment to hear that key. Key notation displayed in the top-right corner changes with your choice in Settings.

Spectrum view

Drop a file onto the Spectrum panel for a Spek-style spectrogram — time across, frequency up, loudness as color — with a dynamic-range slider. Handy for spotting low-quality transcodes.

05Getting files in and out

Between panels

  • Sidebar drag — select rows and drop them on another panel's sidebar button. Routes either move (remove from source) or copy the files; the button highlights when it's a valid target. Dragging out of the Player is always a copy — a playlist keeps every track you send to Analyze, Convert or Rename.
  • From your file manager — dragging files in always adds them.
    • It works the other way too — drag files straight out of Mixed in P into other apps.

Open with Mixed in P

Right-click an audio file in Finder or Explorer and choose Open with → Mixed in P. The app launches if it isn't running, the file lands in Scratch, and it starts playing.

  • Files always go to Scratch — never into the playlist you happen to have open, which would quietly edit a set list you were in the middle of.
  • It never opens a second copy. If Mixed in P is already running, the file goes to the window you already have, and that window comes to the front.
  • It won't cut off what's playing. A file opened mid-track is added to the list and waits its turn. Only an idle player starts playing straight away — which is the point when you open a file to hear it.
  • Several files at once arrive as one batch, sorted by name, and the first one plays. Drag-and-drop is still the way to add tracks without playing anything.
On Windows, "Open with" only appears for one file at a time. That is Windows itself, not Mixed in P — its Open with submenu doesn't offer multi-selection for any app. To open several at once, make Mixed in P your default audio player (below), then select the files and press Enter.

Becoming the default audio player

Settings → Default Audio Player → Make Mixed in P your default audio player. After that, double-clicking an audio file opens it here. This is always your choice: Mixed in P never claims your file types when it installs or on first launch.

06Settings reference

  • Language — many languages supported; restart to apply.
  • Default Audio Player — make Mixed in P the app that opens audio files when you double-click them. See Getting files in and out for what the button does on each platform.
  • Theme — choose a color scheme; restart to apply:
    • Nuevo Leon (default) — a blue-black navy scheme with a sharp neon-yellow accent and mint-green highlights; mirrors the website's look.
    • Dark Mode — a true-black canvas with graphite panels and near-black rows, ported from this documentation site's own palette.
    • Daylight — a light scheme with dark text on pale surfaces, for bright rooms.
    • Slate — a softer dark scheme with muted, low-glare accents, easier on the eyes during long late-night sessions.
    • Neon Dark — the original dark look with neon-yellow accents.

Four of the five color themes (set in Settings → Theme, applied after a restart):

  • Tempo range — lowest/highest BPM (defaults 99–199); narrow it to avoid half/double errors.
  • After analysis — toggle auto-analyze, write BPM to tags, write key to tags, auto-rename, and write key to comment (with energy-first option).
  • Naming format — choose the prefix/suffix layout, e.g. 128 8A - Original_Name or 8A - Original_Name. Affects auto-rename only.
  • Notation — Key Codes (default), Traditional, or Traktor Open Key. Applied live.
  • Energy Tag — where the detected energy level is written. The two options are independent, and you can use both:
    • Write energy level to Comment tag — puts it in the comment, with its own format (7 or Energy 7), a choice of prepend / append / replace, and an option to put energy before the key when both are written there.
    • Write energy level to its own tag field — stores it in a dedicated field instead of prose, where it can be read back exactly. A comment is free text, so a bare 4 sitting in one can't be told apart from any other number; a real field can. Mixed in P reads it back too, so the Player's Energy column fills in for files tagged this way. WAV files can't store it — the format has no tag for it.
  • Playlist Text Size — Small / Medium (default) / Large for the Player's track rows; applied live. Row height and cover art scale with it.
  • Playlist Artwork — how much of each sleeve the Player's Art column shows: Top (default), Middle, or Full. Applied live; Full makes each row tall enough for the whole square. See Playlist columns, artwork & text size.
  • Waveform color — the color of the full-length waveform in the Player. Pick a preset or choose a custom color; applied live. The first option, Default, follows the active theme (each theme has its own waveform color).

Audio visualizations live entirely in the Player: click the eye-icon button in its header and pick one. There is no separate setting to switch on first — choosing a visual is what starts it, and the menu's own Visuals off is how you stop it. Nothing is running until you choose, and your choice is remembered.

  • Backdrop modes (fractal, tunnel chase, oscilloscope, spectrum, wormhole, stream, waveform, fire) render softly behind the playlist while a track plays.
  • Popout modes (fractal, tunnel chase, oscilloscope, spectrum bars, wormhole) open in their own floating window you can move and resize. A popout doesn't reopen on the next launch. Fire and the stream are backdrop-only — both read as lit rows behind a playlist rather than as a whole window.
  • Stream pours a sheet of liquid metal across the playlist in your Waveform color. Its source dances on the beat grid, led by the melody, and every kick brightens what is leaving the nozzle — so a beat travels down the ribbon as a surge rather than flashing the whole picture. It fades to nothing through a silence.
  • Oscilloscope is a green-phosphor CRT with a graticule etched on its faceplate, in the popout window or behind the playlist.
  • Wormhole is the one that listens to the beat: it flies a tunnel of translucent nebula cloud — blue, violet, magenta, teal and green, with the stars showing through it — that turns on the first beat of every bar, and twice in every fourth bar, so the picture moves with the phrasing rather than just with the volume. It takes its tempo from the track's BPM tag, so an analyzed track locks on within a few seconds; an untagged one works the tempo out for itself and is a little less certain about it.
  • Visuals off, at the foot of the menu, stops the current visualization.

Visualizations use your Waveform color setting, and every backdrop except the waveform animates only while a track is playing. Switch modes any time from the same eye-icon menu; the choice applies live. (The moving waveform in the Analyze and Convert panels is separate — it's progress feedback and is always shown.)

Playlists gathers the settings for the playlist tree and the Player's list:

  • When a track is already in the playlist — Ask each time (default), Always add duplicates, or Always skip duplicates. A set list can repeat a track on purpose, so this asks rather than deciding for you; pick one of the others to stop being asked.
  • Keep Scratch between sessions — off by default, so the working list starts empty each launch. Turn it on to have Scratch reopen with whatever was in it. Either way, Save Playlist keeps a copy.
  • Always use full paths in exported playlists — off by default, so exports use paths relative to the playlist file when the tracks sit beside it, and a folder you zip and send still works elsewhere.
  • Export All Playlists… — writes one folder of playlist files mirroring your whole tree; a backup any other app can read.

Online Metadata controls the Discogs lookup described in Fill in tags from Discogs. It is the only part of the app that uses the internet, and it is off until you turn it on:

  • Look up track details online (Discogs) — off by default. While it is off the app makes no network requests and the lookup buttons are not shown anywhere. A lookup sends the artist and title of the track you chose — never your audio, and never your library.
  • Discogs token — a free personal token from your Discogs account, pasted here. Get a Token… opens the page that issues one. Without a token Discogs answers more slowly and without cover images, so the feature needs one to work properly. The token is read-only and you can revoke it on Discogs at any time.
  • Fetch cover art with lookups — on by default. Shows the release's cover next to your file's in the review window so you can compare them. As with every other field, the art is written only if you tick it.

All settings save instantly — there's no Save button.

07History

The History panel keeps a running record of your work in two views, switched with the toggle buttons at the bottom of the panel:

  • Rename History — every batch-rename session, newest first, with its date/time, file count, and a preview of what changed. Select a session to undo it and roll those files back to their previous names.
  • Song Key History — every track you've analyzed, with its detected BPM, musical key and key code, alternative key suggestions, energy level, and confidence scores. A persistent log of past results, so you can look up a track's key without re-analyzing it.

11Harmonic mixing in 60 seconds

Two tracks sound good together when their keys are compatible. Remembering raw key names (F# minor, D♭ major…) is awkward, so Mixed in P uses key codes — a clock-face system where every key gets a number (1–12) and a letter (A for minor, B for major).

The rule of thumb: a track mixes smoothly with any track that shares its number, or sits ±1 on the same letter. So from 8A, good next picks are 8B, 7A, or 9A.

Trusting your ear is best though, so don't get too reliant on the key tags — the key analysis isn't always accurate either.

Prefer traditional note names or Traktor's Open Key format? Switch any time in Settings → Notation. The full mapping is in the key-code reference below.

12FAQ & troubleshooting

A file says "Lossy not allowed" in Convert. The source is MP3, M4A, or OGG. Lossless conversion needs a lossless source (WAV/FLAC/AIFF). Converting to MP3 is fine.

A FLAC (or WAV/AIFF) says "Same format" and won't convert. Converting a file into the format it already has is only offered as a downgrade. Pick a sample rate or bit depth lower than the one shown in the From column — 44.1 kHz/16-bit against a 96 kHz/24-bit source, say — and the row turns Ready. The original is never overwritten; the smaller copy is written alongside it, or into the Save To folder if you set one. Note that setting a Save To folder does not change this: Convert converts, it doesn't copy, so a file already in the target format at the target quality still reads Same format wherever the output is going.

A file says "Would upsample". The chosen sample rate or bit depth is higher than that file's own, shown in the From column. Since a 44.1 kHz/16-bit track can't be made into a 96 kHz/24-bit one, the row is refused rather than inflated. Lower the selectors to match the source (or below) and it converts. In a mixed batch this can hit some files and not others, since the settings apply to the whole list — pick Keep source on the axis you don't need to change and every file converts at its own quality.

I can't find the Look Up Online button. Online lookup is off until you turn it on, and while it is off its buttons are hidden rather than greyed out — the app really does make no network requests. Switch it on in Settings → Online Metadata and paste a Discogs token; the button then appears at the bottom of the Metadata panel (with a file loaded) and in the Player playlist's right-click menu.

Will a lookup overwrite the tags I've already fixed? Not unless you tick them. Any field that already has a value arrives unticked in the review window; only empty fields are ticked for you. If you are deliberately re-tagging a file, Select All ticks everything at once.

Why won't it fetch BPM or key from Discogs? Discogs doesn't hold them — and they are properties of your particular file, not of the record. They stay the product of this app's own analysis, which is measuring the audio you actually have.

A lookup says there was no match. The search runs on the artist and title, falling back to the filename when the tags are empty. If those are wrong or nearly empty, so is the search: correct Artist and Title in the Metadata panel and run it again. Bootleg and unofficial pressings are deliberately filtered out, so a white-label rip may genuinely have nothing to match.

The BPM looks half or double what I expect. Set a tighter tempo range in Settings (e.g. 90–180) so detection stays in DJ-typical territory.

The detected key seems off. Key detection reports a confidence score — low confidence means it's a harder call. Correct the key in the Metadata panel.

My WAV file didn't keep its BPM or key. WAV has nowhere to put them — the format has no tag for BPM, key, or energy, so there is nothing to write to. The Analyze panel says so on the row (WAV file, or Analyzed, no tags once it has run). The results are still on screen, and auto-rename still writes the tempo and key into the filename, which is how a WAV can carry them. For real tags, convert the file to AIFF or FLAC first.

My analysis ran but didn't write anything. Check the Freeze toggle in the Analyze header — while it's on, analysis deliberately writes no tags, no comment, and renames nothing. It always starts off, so it's on because it was switched on this session; click it again and the next run writes normally. If Freeze is off, check the write options under Settings → Key/BPM adding to filename after analysis, and note that WAV files can't store tags at all (above).

I cancelled an analysis but files had already been renamed. Cancel stops the work that hasn't happened yet; it doesn't reverse what already finished. Tracks completed before you clicked keep their results, tags, and new names. Use History to undo the renames.

Compatible Tracks is empty for a track that clearly has matches. Read the line it shows. If it asks you to analyse the track, the seed has no key stored — the panel matches on key, so it has nothing to work from. If it says the track isn't in your library, you're playing a file that was never added to a playlist. If it says nothing mixes with it, the pool really is empty: a compatible key at within ±8% of the tempo (or half/double it) is a narrow ask in a small library, and the fastest fix is to analyse more of your collection.

A preview stopped as soon as I moved the mouse. That's the design: a click starts it and it plays only while the pointer stays on the row's play icon, so a stray swipe across the panel can never fill the room with the wrong track. To hear more of it, hold still — or click again to jump 30 seconds further in. Your main player does not restart afterwards; press play when you want it back.

I hid a playlist column and want the original layout back. Right-click the playlist header and choose Reset Columns at the bottom of the menu. That restores the columns, their order, and their widths as shipped.

My playlist columns rearranged themselves after an update. A newer version ships a different default layout — cover art on by default, filename moved to the end — and it is applied once, which replaces the arrangement you had. Drag the columns back how you like them and it will stick; Reset Columns is always there if you want the shipped layout again.

I renamed files by mistake. Use Undo Last in the Rename panel, or open History to undo any recent batch.

My playlist emptied itself. That will have been Scratch, the working list the Player opens on, which starts empty every launch by design. Turn on Keep Scratch between sessions in Settings → Playlists, and use Save Playlist for anything you want to keep — saved playlists are never cleared.

I deleted tracks from a playlist by accident. Press Ctrl+Z (Cmd+Z). Saved playlists write changes immediately, so undo — not a Save button — is the way back. It covers the current session only.

Search can't find a track by its BPM. That's deliberate. Search covers artist, title, album, filename, comment, and key, but not BPM: as free text a search for 128 would also match years, comments, and filenames containing those digits. Sort by the BPM column in the Player instead.

I opened a file from Finder/Explorer and it went somewhere I didn't expect. Files opened from your file manager always go to Scratch, so they can't disturb a playlist you have open. If something was already playing, the file is added to the list without interrupting it.

Double-clicking an audio file doesn't open Mixed in P. It isn't your default player yet — Mixed in P doesn't claim your file types on its own. Use Settings → Default Audio Player.

"Open with" doesn't appear when I select several files on Windows. Windows doesn't offer that submenu for multiple files, for any app. Make Mixed in P the default audio player, then select the files and press Enter.

My language change didn't take effect. Language applies on the next launch — restart the app.

My theme change didn't take effect. Like language, the color theme applies on the next launch — restart the app.

My audio is playing through the wrong device. Mixed in P uses whatever output device your system has selected at the moment it launches. If you switch outputs afterward — say, from speakers to headphones — the app keeps using the original device until you quit and relaunch. Set your system output first, then start Mixed in P.
